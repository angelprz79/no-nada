# Programas del repositorio

## Listado de alumnos

Este programa se puede usar de dos formas. Elige la que corresponda a tu computadora:

### Opción 1: Windows (la más fácil)

Usa el archivo **`codigos_windows.bat`**. Es un solo archivo y no necesitas instalar nada.

1. Descarga o clona este repositorio.
2. Haz **doble clic** en `codigos-windows.bat`.
3. Sigue las instrucciones que aparecen en pantalla.

Si Windows muestra un aviso de seguridad, elige **Ejecutar** (o **Más información** y luego **Ejecutar de todas formas**).

### Opción 2: Linux (u otro sistema con terminal base unix)

Usa estos dos archivos, que deben estar **juntos en la misma carpeta**:

- `Codigos.sh`
- `cerebro.cpp`

Abre una terminal dentro de esa carpeta y escribe:

```
bash Codigos.sh
```

Esta opción necesita tener el compilador **g++** en el equipo.

### Cómo se usa el programa

1. Escribe la cantidad de alumnos que vas a registrar.
2. Elige una opción del menú escribiendo su número:
   - **1:** registrar alumnos con número de lista. Escribe el nombre, un espacio y el número, por ejemplo `Ana 5`.
   - **2:** registrar alumnos sin número de lista. Escribe solo el nombre y el programa les asigna el número por orden alfabético.
   - **3:** ver los alumnos ordenados por nombre.
   - **4:** ver los alumnos ordenados por número de lista.
   - **5:** salir.

## Restaurante

El programa **Restaurante** es independiente de **Listado de alumnos**.

- **Windows:** haz doble clic en `restaurante.bat`.
- **Linux:** abre una terminal en la carpeta y escribe `bash Restaurante.sh`.
